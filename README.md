# FilmLog

A mobile movie discovery and tracking app built with Ionic and Angular. Users search real movies through a live IMDb API and manage a personal Watchlist and Watched List.

## Tech stack
- Ionic and Angular
- Angular HttpClient with an external IMDb API
- Ionic Storage for local data
- SCSS styling

## Features
- Simulated login and signup using local storage
- Movie search with a text filter
- Movie details page (title, release year, cast, poster)
- Add to Watchlist and mark as Watched
- Remove movies from either list
- Reset a watched movie back to the Watchlist

## How to run
1. Install dependencies: `npm install`
2. Start the app: `ionic serve`
